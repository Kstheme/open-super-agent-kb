# 应用优先，账本结构单列在 spec/

开源早期，框架缺少让人先愿意相信的入口，应用才有可演示的结果。因此交付一个 clone 下来就能跑的应用；同时把账本结构写在 `spec/` 并单独版本号，使他人可以写只读查看器、替换抽取器，或把账本导出到别的系统。

不成立独立规范项目：不设 RFC 流程和治理委员会，schema 跟随代码演进，v0.x 允许破坏性变更，v1.0 后只增字段不改语义。

## Considered Options

- **纯框架/库**：要求使用者先接受陌生抽象再验证价值，开源早期转化率极低。
- **只用应用、不公开结构**：失去被第三方集成和复用的可能，也失去"格式即护城河"的路径。
- **独立规范项目**：治理成本高于当前阶段能承担的范围。
